# Домашнее задание к работе 3
## Условие задачи

Написать и отладить программу вычисления расстояния
между двумя точками, заданными координатами x и y.

**Вариант 13**

## Алгоритм

1. **Начало**
2. Ввести исходные данные с клавиатуры:
    `x1`, `y1`: координаты первой точки.
    `x2`, `y2`: координаты второй точки.
3. Вычислить разности координат:
    `dx` = `x2` − `x1`
    `dy` = `y2` − `y1`
4. Вычислить расстояние между точками:
    `distance` = √(`dx` * `dx` + `dy` * `dy`)
5. Вывести результаты расчётов с подстановкой всех значений в текст.
6. **Конец**

## Код

```c
{
    setlocale(LC_ALL, ".UTF-8");
    
    double x1, y1, x2, y2;

    printf("Введите x первой точки: ");
	scanf("%lf", &x1);
    printf("Введите y первой точки: ");
	scanf("%lf", &y1);
    printf("Введите x второй точки: ");
    scanf("%lf", &x2);
	printf("Введите y второй точки: ");
	scanf("%lf", &y2);

    double dx = x2 - x1;
    double dy = y2 - y1;
    double distance = sqrt(dx * dx + dy * dy);

    printf("Первая точка: (%.2f; %.2f)\n", x1, y1);
    printf("Вторая точка: (%.2f; %.2f)\n", x2, y2);
    printf("Расстояние между точками: %.2f\n", distance);

    getchar();
    return 0;
}
```
